# Challenge hostile input admission

Read [the testing contract](../CONTRACT.md).

Start with small accepted scaffold/independently known result. Mutate named grammar/identity/length/state/authority rule; preserve bytes reaching intended seam. Separate valid-shaped unauthorized cases/malformed syntax.
