# Accept integrated input-to-output behavior

Read [the testing contract](../CONTRACT.md).

Freeze integrated source/configuration/dependencies/fixtures and actual candidate artifacts. Establish expected facts before viewing production output. Use the real admitted route, including protected effects only in an owned disposable Windows environment.

Select representative known-answer scenarios across declared scope: analytic clock trajectories and selection, strict input rejection, status/policy persistence, native authority or complete MSI lifecycle. Inspect actual admitted input bytes and actual resulting status, journals/files, acknowledgements or installed components with read-only tools; a verifier report alone is insufficient.

Freeze a finite case/fact inventory with independently justified preserve/transform/omit/reject obligations, cardinality and forbidden effects. Include applicable omitted/default options, cold/warm/cache, replay, repeat and restart paths beside explicit healthy controls. Use [case design](../references/case-design.md) for interacting conditions; select from actual production consumers and name unassessed consumers.

Compare each promised fact independently before comparing formats. Confirm that consumer declarations describe the same output units, identity, trust, age and representation. Preserve legitimate variation and intentional omissions backed by the contract. A round trip through shared production helpers is not independent truth.

Verify observer sensitivity using task-owned wrong, missing and unexpected-output fixtures. These controls challenge the observer; they do not replace processing through the real candidate entrypoint. Retain the selected, executed and checked record/fact inventory, promised absences and first mismatches. A report count or decoding success alone cannot establish those comparisons.

When retained state or a release artifact is in scope, inspect and reconcile that actual state/artifact as well as fresh fixture processing. Fresh success cannot qualify stale journals, caches, installed components or earlier packaged bytes. Bind consumer declarations to the exact payload they reference; substitutions leave the bypassed path unqualified.

Use complementary reviewers for broad independent areas when available; assign seam reconciliation to one owner. Record expected versus observed facts, candidate hashes, controls, exact environments and unresolved scope. Only completed selected evidence can support [final qualification](../qa-final-qualification/SKILL.md).
