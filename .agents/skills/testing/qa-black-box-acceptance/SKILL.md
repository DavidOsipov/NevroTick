# Accept integrated input-to-output behavior

Read [the testing contract](../CONTRACT.md).

Freeze integrated source/configuration/dependencies/fixtures/actual candidate artifacts. Establish expectations before production output. Use real admitted route; protected effects only in owned disposable Windows environment.

Select representative declared-scope known-answer scenarios: analytic clock trajectories/selection, strict input rejection, status/policy persistence, native authority, complete MSI lifecycle. Read-only inspection: actual admitted bytes/resulting status/journals/files/acknowledgements/installed components; verifier report alone insufficient.

Freeze a finite case/fact inventory with independently justified preserve/transform/omit/reject obligations, cardinality and forbidden effects. Include applicable omitted/default options, cold/warm/cache, replay, repeat and restart paths beside explicit healthy controls. Use [case design](../references/case-design.md) for interacting conditions; select from actual production consumers and name unassessed consumers.

Compare each promised fact independently before formats. Confirm consumer declarations match output units/identity/trust/age/representation. Preserve contract-backed legitimate variation/intentional omissions. Shared-production-helper round trip is no independent truth.

Verify observer sensitivity using task-owned wrong, missing and unexpected-output fixtures. These controls challenge the observer; they do not replace processing through the real candidate entrypoint. Retain the selected, executed and checked record/fact inventory, promised absences and first mismatches. A report count or decoding success alone cannot establish those comparisons.

For in-scope retained state/release artifact, inspect/reconcile actual state/artifact plus fresh fixture processing. Fresh success cannot qualify stale journals/caches/installed components/earlier packaged bytes. Bind consumer declarations to exact referenced payload; bypassed paths remain unqualified.

Use complementary reviewers for broad independent areas when available; assign seam reconciliation to one owner. Record expected versus observed facts, candidate hashes, controls, exact environments and unresolved scope. Only completed selected evidence can support [final qualification](../qa-final-qualification/SKILL.md).
