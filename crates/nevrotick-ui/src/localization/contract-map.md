# Text contract and evidence owners

The code-owned metadata, checked constructors and actual source sinks are three
independent inputs. This map describes the text-contract-2 candidate; it is not a
human language approval, a native execution receipt or a release decision.

| Contract | Enforcing owner | Discriminating evidence |
| --- | --- | --- |
| Exact retained strict UTF-8, no BOM/repair | `json::read` and preflight | Invalid bytes/BOM; valid escaped scalar still rejected by repertoire |
| Closed schema2/text2, complete exact IDs | private `Catalog::checked`, `contract::SPECS` | Old/future version, fingerprint mismatch, missing/extra/retired ID, empty/blank required text |
| Duplicate decoded keys before repeated value | JSON map seed/shared `Budget` | Literal/escaped duplicate at root/messages/entry/args/forms; full valid neighboring catalog |
| Fixed finite representation/work | JSON/CBOR readers and shared counters | Encoded/decoded/depth/node/map/field/token/work boundary controls |
| Same emoji-free scalar profile | `Budget::text`, garde rule, `repertoire` | Emoji/sequence/hidden scalars reject; plain digits, `#`, `*`, selected punctuation survive |
| Independent canonical binary admission | `cbor::Reader` and checked catalog | Minimal vector; nonminimal/order/type/duplicate/trailing failures |
| Closed typed formatting | `UiText`, `Snapshot::minutes`, `PlainText` | Positive minute inputs, placeholders/forms, post-render UTF-8/UTF-16 bounds |
| Approval is independent of valid data | private `approvals::Authority`, empty production `REVIEWS` | Public unapproved pack/bootstrap deny; fixed authority exists only under `cfg(test)` |
| One coherent generation | `CatalogBindingState`, `UiFeedbackSet`, `catalog_projection` | Prepare/check before owner replacement and one setter; old immutable model and raw drafts retained |
| GUI-version compatibility | text version + semantic fingerprint + retained v1 baseline | Both semantic-delta directions require a version bump; GUI build-only changes remain compatible |
| Forward and reverse GUI coverage | `check_ui_text_coverage`, instance-sensitive Slint graph | Added unnamed control, removed sink/orphan ID, duplicate alias/index, dormant/cross-instance source failures |
| Native-only consumers are real | `native_text_graph` closed host/API witness | Remove entry/install/row/label argument/DOM field/Show/feedback caller and coverage fails |
| Code generation cannot execute translated data | bounded `generate-ui-text`, typed metadata, pinned template | Explicit source SHA, unchanged v1 baseline, reference text confined to inert fingerprint output |

`contract-source.json` retains stable ordinals and explicit inactive states.
`runtime-text-sinks.json` records closed typed feedback destinations; it cannot
create a renderer. The independent source gate observes the corresponding Rust
receivers and actual AppWindow text leaves. `consumer-map.json` and initial review
pins remain historical 184-ID evidence, not the current inventory or oracle.
There is no runtime-fetchable schema file or catalog-selected validator.

The native source chain prepares current-snapshot labels before actual menu/DOM
sinks; only the two consumed reserved tray IDs become active. Other future tray
meanings remain reserved. The obsolete unconditional “no notification submitted”
Settings paragraph is retired with its ordinal preserved; actual rejection
feedback retains its separate truthful no-submission tail. Native acceptance,
indeterminate and duplicate-test feedback keep distinct closed meanings.

The production ledger is empty. Human warning/action/accessibility review,
installed-resource custody, native runtime/UIA/Narrator, layout expansion and
service/backend qualification remain separate evidence. Existing fuzz/analysis,
D1/D3 and other release holds are not changed by this contract update.
