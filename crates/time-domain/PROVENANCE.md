The [source ledger](../../tasks/s0.1-chrony-ledger.json) owns the retrieved source
and [S1.1c task](../../tasks/s1.1-time-domain.md) owns the independently reviewed
numeric contract and candidate-specific evidence. Local code is authored for
that exact integer contract, retaining the related upstream source context and
notices; the rejecting TDD baseline contains no implemented upstream algorithm.
Later implementation and its execution must be recorded against the candidate.

Deliberate scope differences: explicit inclusive numeric windows replace an
implicit build/date pivot; Q32 coordinates and Q33 offset numerators preserve
exact raw bits and half-ticks; signed raw RTT is not precision-clamped or treated
as an admitted sample. Rounding is explicit nearest-ties-even with exact residual.
No floating interval conversion, platform clock, native time mapping, NTP
association, precision/frequency/chronology policy, authentication, state update,
clock correction or upstream default-era policy is ported. Input windows carry
no anchor trust. Numeric limits are engineering bounds rather than release date
or recovery policy.

The four arithmetic oracle expectations come from literal independently authored
[S1.1 fixture specifications](../../tasks/s1.1-exchange-vectors.json), augmented by
analytic integer trajectories, independent finite candidate enumeration and exact
rounding literals. They are not generated by production code or taken solely from
upstream output. Upstream reuse supplies no presumption of correctness or safety.
