# NevroTick — AVIF kit v1

84 AVIF-файла на основе проверенного растрового комплекта **NevroTick PNG/JPEG v1.1**. Использована исправленная ростовая фигура с одним зрачком в каждом глазу. Новая генерация персонажа при конвертации не выполнялась.

## Размер

Суммарный размер 84 исходных PNG/JPEG: **30,393,408 байт**. Суммарный размер 84 AVIF со встроенными метаданными: **4,512,924 байт**. Уменьшение — **85.15%**. Здесь сравниваются именно изображения; служебные JSON/XMP и документы не входят в эти суммы.

| Изображение | Исходный PNG, байт | AVIF с метаданными, байт | Уменьшение |
|---|---:|---:|---:|
| Голова | 1,116,487 | 89,233 | 92.0% |
| Бюст | 2,483,906 | 266,446 | 89.3% |
| Ростовая фигура | 1,294,921 | 114,834 | 91.1% |

Полные метаданные добавляют в среднем 6.41 КБ на изображение. У иконок 16–64 px этот объём может превышать размер самой картинки, поэтому отдельные маленькие AVIF больше исходного PNG. Все 84 изображения сохраняют запрошенные авторские, контактные и лицензионные сведения.

## Сжатие и качество

Размеры изображений не уменьшались. Кодирование: AOM / libavif, 8 bit, 4:4:4, full range. Для прозрачных изображений альфа-канал сохранён без потерь и проверен побитово. Цвет сжат с потерями.

- Q45 — крупные персонажи, портреты, большинство прозрачных изображений и обычных композиций.
- Q60 — логотипы и надписи на непрозрачных подложках, а также таблица размеров иконок: повышенное качество уменьшает рябь по краям мелкого текста.
- Q85 — изображения с максимальным размером до 64 px: сохраняет цвета и детали маленьких иконок лучше, чем общий профиль.

Непрозрачные рабочие версии построены из соответствующих проверенных PNG с подложками, чтобы не повторять JPEG-сжатие. Исходные обзорные JPEG конвертированы как готовые композиции.

Профили выбраны по визуальному сравнению 35 проб и композиций: глаза, часы, руки, штриховка, маленькие иконки, текст. В просмотренных пробах не обнаружено новых смысловых дефектов. Это выборочная визуальная оценка качества сжатия. Техническая проверка выполнена для каждого из 84 конечных файлов.

## Встроенные метаданные

## Проверка

Все **84/84** AVIF полностью декодируются; размеры совпадают с ожидаемыми. Прозрачность совпадает с исходным PNG. Встроенные поля прочитаны обратно и сверены с индивидуальными спецификациями. ExifTool вернул **OK** для каждого файла без предупреждений и ошибок валидации. Пиксели, декодированные до и после встраивания метаданных, совпали побитово; это проверка операции записи метаданных, а не утверждение о побитовом совпадении RGB после сжатия с исходным PNG.

Проверенные исходные изображения сохранены отдельно в ранее подготовленном PNG/JPEG-комплекте v1.1. Этот архив содержит только AVIF-производные и сопровождающие их документы.
