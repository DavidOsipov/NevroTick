# NevroTick — текущий HTML-прототип v0.4

[Открыть автономный макет](NevroTick-UI-v0.4.html) · [Инструкция и сценарии](README-RU.md) · [Обновление из About](README-RU.md#обновление-приложения-из-about) · [Трей и выход из приложения](review/tray/REPORT-RU.md) · [Аудит статусов и уведомлений](review/status-notifications/REPORT-RU.md)

Этот комплект заменяет v0.2 как текущий визуальный и интерактивный референс по поручению владельца от 5 ноября 2026 года. [v0.2](../nevrotick-design-v0.2/README.md) сохранён как исторический материал со своими исходниками, сценами и результатами проверки. Его идентификаторы сцен несовместимы с v0.4; старые deep links нельзя переносить в новый HTML без сопоставления.

В макете 30 сцен состояния времени, Simple и Power user, Settings/About в обоих режимах, целые интервалы от одной минуты, Roughtime, управление согласованной парой служб, автозапуск/полное отключение, явная передача управления Windows Time и образцы локальных уведомлений Windows. Все операции используют данные в памяти страницы. Реальные службы, уведомления Windows, сеть, UAC, установка пакетов и часы здесь не вызываются.

**Дополнение от 25 ноября 2026 года:** в About добавлен интерактивный образец
ручного обновления по [OD-05 §7.10](../nevrotick-owner-decisions.md#710-tuf-authenticated-direct-msix-updater--25-november-2026).
**Check for updates** показывает проверку, затем допустимое предложение с
**Update now / Later**. Одно принятие запускает показ последовательности
**Downloading → Verifying → Installing → результат**, без отдельного Download
или повторного подтверждения установки. Версии `1.0.0 → 1.1.0` — вымышленные
данные демонстрации. Сценарии отказа проверки, запрета политики и неизвестного
исхода выбираются на русской панели проверяющего вне приложения.
См. [маршрут осмотра](README-RU.md#обновление-приложения-из-about) и
[границу реализации и проверки](../../tasks/slint-gui-handoff.md#html-updater-prototype--25-november-2026).

**Дополнение от 5 ноября 2026 года:** под окном появился интерактивный образец
трея Windows: значок со статусом, подсказка, контекстное меню и режим сравнения
контрастности. Трей по умолчанию выключен; настройки доступны в Simple и Power
user. Выход через Quit UI требует предупреждения о продолжающейся работе служб
и предлагает переход в Settings → Background service. Остановка и полное
отключение остаются отдельными действиями. См. [проверку и изображения](review/tray/REPORT-RU.md).

Для нативной реализации сохраняются [каноническая архитектура](../windows-time-architecture.md), [UI-M0 и D1–D3](../windows-time-architecture.md#165-restricted-first-ui-milestone-ui-m0) и [задача UI-M0](../../tasks/ui-m0.md). [OD-13 от 5 ноября 2026 года](../nevrotick-owner-decisions.md#17-od-13--slint-as-the-default-ui-toolkit) выбирает полную замену Win32 UI на Slint; текущий Windows entrypoint уже использует Slint, а Rust и необходимые адаптеры Windows API сохраняются. Состояние нативного исходного кода и его отдельные доказательства описаны в [GUI handoff](../../tasks/slint-gui-handoff.md). HTML-образец не реализует нативный updater, не закрывает native/release gates и не снимает execution holds или отложенные требования D1–D3. Упоминания Win32 UI и прежней общей лицензии в сохранённых отчётах относятся к их историческим кандидатам. AVIF и уведомления о правах сохранены; [бренд-кит](../NevroTick-AVIF-kit-v1/README.md) остаётся отдельным источником графики.

## Исходники и проверка

Основные файлы: `src/`, `assets/`, `tests/`, `build.cjs`; многофайловый вход — `index.html`. Для сборки и unit-тестов не нужны npm-пакеты:

```sh
node build.cjs
node --test tests/*.test.cjs
node tests/render-fixtures.cjs /tmp/nevrotick-views.json
python3 tests/check_structure.py /tmp/nevrotick-views.json
sha256sum --check SHA256SUMS.txt
```

**Проверка интегрированного изменения updater:** сборка прошла; автономный HTML
занимает 902 673 байт. Проверка синтаксиса трёх JS-исходников, все 232 Node-теста
и структурная проверка 1 561 варианта HTML прошли. CSP соответствует конечному
скрипту, внешних зависимостей автономного файла нет, исходные AVIF сохранены.
Браузерная и визуальная проверка текущей сборки остаются невыполненными из-за
недоступного браузерного окружения; нативная Windows-проверка не проводилась.

Python-проверка требует lxml; браузерные проверки — Playwright и работоспособный Chromium. Команды перечислены в [README-RU.md](README-RU.md#основа-и-пересборка). Результаты изменения updater записываются в [текущем GUI handoff](../../tasks/slint-gui-handoff.md#html-updater-prototype--25-november-2026). Отчёты внутри `review/`, включая [трей](review/tray/REPORT-RU.md) и [статусы/уведомления](review/status-notifications/REPORT-RU.md), относятся только к указанным в них прежним кандидатам.

В этом комплекте отсутствует часть вложений двух исторических отчётов:
`review/status-notifications/BASELINE-VISUAL-AUDIT-RU.md` ссылается на снимки
кандидата `ed523ef…`, а `STATUS-FIX-PRELIMINARY-BROWSER.md` — на каталог
`status-fix-audit/` кандидата `cd90ed0`. Их ссылки сохранены как исторические;
эти отсутствующие вложения не подтверждают текущий макет. Доступные изображения
и результаты трея перечислены в его отчёте выше. Старые результаты не переносятся
на текущую сборку автоматически.

В историческом `review/next-iteration/APPROVED-DESIGN-RU.md` также сохранены
ссылки вида `/workspace/NevroTick/docs/…:строка` из исходного окружения автора.
Они не являются переносимыми ссылками на файлы этого комплекта или текущие
строки документации. Оригинальный отчёт не изменён; актуальные требования
проверяются по [документации репозитория](../README.md), а фактическая реализация
и незавершённые проверки — по [GUI handoff](../../tasks/slint-gui-handoff.md).
