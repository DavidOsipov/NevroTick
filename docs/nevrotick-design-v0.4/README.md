# NevroTick — текущий HTML-прототип v0.4

[Открыть автономный макет](NevroTick-UI-v0.4.html) · [Инструкция и сценарии](README-RU.md) · [Трей и выход из приложения](review/tray/REPORT-RU.md) · [Аудит статусов и уведомлений](review/status-notifications/REPORT-RU.md)

Этот комплект заменяет v0.2 как текущий визуальный и интерактивный референс по поручению владельца от 5 ноября 2026 года. [v0.2](../nevrotick-design-v0.2/README.md) сохранён как исторический материал со своими исходниками, сценами и результатами проверки. Его идентификаторы сцен несовместимы с v0.4; старые deep links нельзя переносить в новый HTML без сопоставления.

В макете 30 сцен, Simple и Power user, Settings/About в обоих режимах, целые интервалы от одной минуты, Roughtime, управление согласованной парой служб, автозапуск/полное отключение, явная передача управления Windows Time и образцы локальных уведомлений Windows. Все операции используют данные в памяти страницы. Реальные службы, уведомления Windows, сеть времени, UAC и часы здесь не вызываются.

**Дополнение от 5 ноября 2026 года:** под окном появился интерактивный образец
трея Windows: значок со статусом, подсказка, контекстное меню и режим сравнения
контрастности. Трей по умолчанию выключен; настройки доступны в Simple и Power
user. Выход через Quit UI требует предупреждения о продолжающейся работе служб
и предлагает переход в Settings → Background service. Остановка и полное
отключение остаются отдельными действиями. См. [проверку и изображения](review/tray/REPORT-RU.md).

Для будущей реализации сохраняются [каноническая архитектура](../windows-time-architecture.md), [UI-M0 и D1–D3](../windows-time-architecture.md#165-restricted-first-ui-milestone-ui-m0) и [задача UI-M0](../../tasks/ui-m0.md). [OD-11 от 5 ноября 2026 года](../nevrotick-owner-decisions.md#15-od-11--replace-the-win32-ui-with-slint) выбирает полную замену Win32 UI на Slint; Rust и необходимые адаптеры Windows API сохраняются. Импорт макета не реализует эту замену и не закрывает native/release gates, не снимает execution holds и отложенные требования D1–D3. Упоминания Rust/Win32 в исходном README-RU, About и сохранённых отчётах описывают базовую версию до миграции; будущим UI управляет OD-11. AVIF и уведомления о правах сохранены; [бренд-кит](../NevroTick-AVIF-kit-v1/README.md) остаётся отдельным источником графики.

## Исходники и проверка

Основные файлы: `src/`, `assets/`, `tests/`, `build.cjs`; многофайловый вход — `index.html`. Для сборки и unit-тестов не нужны npm-пакеты:

```sh
node build.cjs
node --test tests/*.test.cjs
node tests/render-fixtures.cjs /tmp/nevrotick-views.json
python3 tests/check_structure.py /tmp/nevrotick-views.json
sha256sum --check SHA256SUMS.txt
```

Python-проверка требует lxml; браузерные проверки — Playwright и Chromium. Команды перечислены в [README-RU.md](README-RU.md#основа-и-пересборка). Исторические отчёты внутри review/ относятся к указанным в них кандидатам; текущие — [status-notifications](review/status-notifications/REPORT-RU.md).

В этом комплекте отсутствует часть вложений двух исторических отчётов:
`review/status-notifications/BASELINE-VISUAL-AUDIT-RU.md` ссылается на снимки
кандидата `ed523ef…`, а `STATUS-FIX-PRELIMINARY-BROWSER.md` — на каталог
`status-fix-audit/` кандидата `cd90ed0`. Их ссылки сохранены как исторические;
эти отсутствующие вложения не подтверждают текущий макет. Доступные изображения
и результаты трея перечислены в его отчёте выше. Старые результаты не переносятся
на текущую сборку автоматически.

Исторический исходный импорт: production source `62aa9713548f8bfefc7ea087a01d788bc6f39c10`, тестовый commit `bcbd4fc30becad3c0dd5109b7df93c3bc21c0099`, локальный комплект `50a366c`. Его SHA-256: `4d8c3d211ec19ddea21a4b37d6b164f453a8ab8352cca6c554c8c8ac28370f86`. Текущая версия с треем намеренно отличается; её идентичность и проверки записаны в [новом отчёте](review/tray/REPORT-RU.md).

`IMPORTED-SHA256SUMS.txt` сохраняет исторический manifest исходного комплекта; он не описывает намеренно изменённые файлы текущей версии. `SHA256SUMS.txt` покрывает текущие файлы каталога, включая инструкции и дополнение трея. Контрольные суммы не являются цифровой подписью. Проверки импорта и изменения записаны в задаче UI-M0; Windows-доставка уведомлений и нативная доступность этими HTML-проверками не подтверждаются.
